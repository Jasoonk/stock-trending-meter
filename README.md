# 美股儀表板 —— 總經流動性象限 ＋ 散戶情緒

用 **美元指數（DXY）的方向 × 美債殖利率曲線（10Y−2Y）的方向**，判斷目前處於哪一種流動性環境，
以及各類資產「理論上」該怎麼表現 —— 再用實際報酬檢驗市場有沒有照劇本走。

**決策輔助，不是交易訊號。** 象限描述的是「過去 N 個交易日的方向」，不是預測。

線上版：https://jasoonk.github.io/stock-trending-meter/

---

## 四象限

| 象限 | DXY | 殖利率曲線 (10Y−2Y) | 驅動主因 | 流動性與資產 |
|---|---|---|---|---|
| **Q1 流動性緊縮** | 走強 ↑ | 走弱 ↓：2Y 上升比 10Y 快 | 緊縮預期升溫（通膨反彈、聯準會轉鷹） | 殺估值：科技、加密、黃金、新興市場同步承壓；短債與美元最抗跌 |
| **Q2 結構性分化** | 走強 ↑ | 走強 ↑：10Y 上升比 2Y 快 | 經濟過熱或財政發債壓力，長端期限溢價上升 | 強美元壓大宗與跨國企業；美國價值股、金融股抗跌；長債受創 |
| **⭐ Q3 流動性釋放** | 走弱 ↓ | 走強 ↑：2Y 下跌比 10Y 快 | 聯準會轉向寬鬆／啟動降息 | 利率敏感資產率先反彈（加密、黃金、高 Beta、新興市場）；美元與短債收益率下滑 |
| **Q4 避險主導** | 走弱 ↓ | 走弱 ↓：10Y 下跌比 2Y 快 | 衰退預期主導，聯準會尚未大幅降息 | 長天期美債最佳；高槓桿風險資產波動加劇，防信用利差擴大 |

**Q3 是頁面頂端的「流動性釋放訊號」**：🟢 觸發中／🟡 醞釀中（方向對但幅度在死區內）／⚪ 未觸發。

## 散戶情緒（AAII）

AAII 每週四公布的調查：「未來 6 個月股市會漲、持平、還是跌？」頁面顯示：

- 看多／中立／看空比例，對照 1987 年以來的長期平均與上週變化
- **看多−看空利差的歷史百分位** → 極度悲觀（最低 10%）／偏悲觀（10–25%）／中性／偏樂觀（75–90%）／極度樂觀（最高 10%）
- **歷史對照**：過去落在同一區間的週，S&P 500 之後 26 週的報酬中位數與上漲機率，對比全部週的基準。
  相鄰週的前瞻期間重疊，獨立樣本遠少於表面週數 —— 只當背景，不是勝率。

情緒常被當反向指標，但「極度悲觀」常出現在下跌途中，不代表馬上見底。

## 怎麼判斷

- 方向 = 今天的值 對比 **N 個交易日前**。可切換 **1 個月（20 日）**或 **3 個月（60 日）**。
- **死區**：變動太小時標為「方向不明確」（1 個月：DXY ±0.5%、利差 ±5bp；3 個月：±1.0%、±10bp）。
- **非典型**：象限只看 DXY 與利差方向，但表格同時假設了殖利率水準的走向（Q1/Q2 殖利率上升、Q3/Q4 下跌）。若不符就標「非典型」——代表驅動因素和表格假設不同，可信度要打折。
- **劇本檢驗**：拿 12 檔代表資產的同期報酬比對。預期「強」的應高於全體中位數、預期「弱」的應低於，顯示命中數（例如 6/6）。這是在問「市場現在真的照這個象限在走嗎？」

> 1 個月視角反應快但容易來回翻轉（過去一年 Q3 出現的 9 段裡有 5 段只維持 1 天）。
> 3 個月視角較平滑。建議用 1 個月看早期跡象、用 3 個月確認。

## 資料來源

| 資料 | 來源 | 備註 |
|---|---|---|
| 2Y、10Y 殖利率 | **美國財政部** Daily Treasury Par Yield Curve | 官方、免金鑰。2Y 與 10Y 同一來源，避免口徑差污染利差 |
| DXY | Yahoo `DX-Y.NYB` | 丟棄週日空 K 棒；與 UUP 日變動相關 0.83（已驗證日期對齊） |
| 12 檔驗證資產 | Yahoo | QQQ、ARKK、BTC-USD、GLD、EEM、DBC、VTV、XLF、TLT、HYG、SHY、UUP |
| 市場情緒 | CNN 恐慌貪婪指數 | 非官方端點，抓不到時自動隱藏 |
| 散戶情緒 | AAII Investor Sentiment Survey | 每週抓官網表格（近 ~20 週）；1987 年起的歷史由 `backfill_aaii.py` 從官方 `sentiment.xls` 一次灌入 |
| S&P 500 | Yahoo `^GSPC` | 只存每個 AAII 週的收盤，用來算歷史對照 |

⚠️ **不要用 Yahoo 的 `2YY=F` 當 2Y 殖利率**：建置時發現它數值連續數週不變，是無成交的死合約。

## 檔案

| 檔案 | 作用 |
|---|---|
| `regime.py` | **象限分類器（單一真相）**、象限定義、資產預期、劇本檢驗。前端不重算，避免兩份實作漂移。 |
| `aaii.py` | AAII 網頁解析、百分位區間、歷史對照統計。 |
| `fetch.py` | 抓資料 → `macro.db` → `data.json`。只用 Python 標準庫。 |
| `backfill_aaii.py` | 一次性灌 AAII 歷史（需 `pip install xlrd`）。`macro.db` 已含歷史，平常不用跑。 |
| `macro.db` | 每日序列（`macro_daily`、`asset_daily`）、象限歷史（`regime_history`，含 `param_version`）、恐慌貪婪、AAII 每週（`aaii_weekly`，含當週 S&P 500 收盤）。 |
| `index.html` | 單頁儀表板，只負責顯示 `data.json`。 |
| `.github/workflows/update.yml` | 每日 13:00 UTC 自動抓取並 commit。 |

修改 `regime.py` 的 `PARAMS` 或資產預期會改變 `param_version`；比較歷史訊號時應依版本分段。

## 本機執行

```bash
python fetch.py
python -m http.server 8137
```

開 `http://127.0.0.1:8137/index.html`。或直接雙擊 `開啟儀表板.bat`。
